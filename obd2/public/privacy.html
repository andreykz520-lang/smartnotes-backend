2. Основные понятия

  • Сервис / Программа — программное обеспечение «OBD2 SCAN AI» для мобильных устройств Android и веб-сайт https://obd2scanai.ru.
  • Пользователь — любой посетитель веб-сайта и/или пользователь мобильного приложения OBD2 SCAN AI.
  • Персональные данные — любая информация, относящаяся прямо или косвенно к определенному Пользователю.

3. Какие данные обрабатывает Оператор

Оператор может обрабатывать следующие данные Пользователя:

  • Адрес электронной почты (E-mail) — для отправки лицензионных ключей активации, кодов подтверждения (OTP) и чеков;
  • Обезличенный идентификатор устройства (Android Device ID / Hardware Hash) — для технической привязки лицензии PRO к смартфону Пользователя;
  • Технические данные подключения сканеров (Bluetooth MAC-адрес адаптера, IP/порт Wi-Fi адаптера) — исключительно локально на устройстве для установления соединения по протоколам OBD-II;
  • Обезличенные диагностические коды ошибок (DTC) и параметры датчиков — для формирования диагностических отчетов и запросов к ИИ-ассистенту.

4. Цели обработки персональных данных

  • Предоставление доступа к функционалу мобильного приложения OBD2 SCAN AI;
  • Генерация, учет и восстановление лицензионных ключей PRO и PRO+;
  • Информирование Пользователя посредством отправки электронных писем с кодами активации и чеками;
  • Обеспечение технической поддержки и клиентского сервиса.

5. Правовые основания обработки

Оператор обрабатывает персональные данные Пользователя только в случае их заполнения и/или отправки Пользователем самостоятельно через формы на сайте https://obd2scanai.ru, в мобильном приложении или в официальном Telegram-боте.
